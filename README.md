## Repository structure
Each task has its own folder (`Task01` through `Task12`). Java source files are named after their main class. Tasks containing standalone programs can be compiled and run from their folder.

## Compile and run
Open a terminal in the relevant task folder and run:

```bash
javac FileName.java
java MainClassName
```

For programs with multiple source files, compile all Java files together:

```bash
javac *.java
java MainClassName
```
